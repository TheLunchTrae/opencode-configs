# Personal OpenCode configs

This repository contains my personal OpenCode configuration.

## Setup

### TokenEconomizer

[Per Original Docs](https://github.com/microsoft/TokenEconomizer/blob/main/plugin/README.md#opencode)

Requirements: OpenCode V1 1.19.x and Python 3.10+ on `PATH`.

1. Keep `plugins/tokeneconomizer.ts` and `vendor/TokenEconomizer/` together in your active configuration directory.

2. Restart OpenCode.
